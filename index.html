Política de Privacidad

Aplicación: NeotixTrainer

Última actualización: 16/04/2026

1. Recogida y Uso de Datos

Para ofrecer nuestros servicios, recopilamos la siguiente información personal gestionada de forma segura a través de Supabase:

  • Identificadores: Correo electrónico para la creación de cuenta y autenticación.
  • Credenciales: Contraseñas almacenadas mediante hashing (cifrado no reversible).
  • Contenido del usuario: Fotografía de perfil (almacenada en Supabase Storage) si el usuario decide subirla.

No vendemos ni compartimos estos datos con anunciantes ni terceros ajenos al servicio.

2. Procedimiento de Eliminación de Datos

Cuando un usuario solicita la eliminación de su cuenta, nuestro sistema ejecuta un proceso de borrado total en nuestros servidores de Supabase:

  • Borrado Instantáneo: Se eliminan todas las filas vinculadas al ID del usuario en la base de datos (PostgreSQL).
  • Limpieza de Archivos: Se purgan de forma definitiva las imágenes subidas por el usuario en nuestros cubos de almacenamiento.
  • Baja de Autenticación: El registro de acceso (email) se elimina de los registros de Supabase Auth, impidiendo cualquier acceso futuro.

3. Cómo Solicitar la Eliminación

Usted tiene el control total sobre sus datos. Puede solicitar la eliminación de las siguientes maneras:

A. Desde la Aplicación (Recomendado)

Vaya a Ajustes > Mi Perfil > Eliminar Cuenta. Tras confirmar su decisión, sus datos serán borrados de forma inmediata y su sesión se cerrará automáticamente.

B. Solicitud Externa (Web/Soporte)

Si ya no tiene instalada la aplicación o prefiere que lo hagamos manualmente, puede solicitarlo enviando un correo a nuestro soporte técnico:

Solicitar Borrado por Email

4. Seguridad

Utilizamos cifrado SSL/TLS para la transmisión de datos y políticas RLS (Row Level Security) para asegurar que nadie, excepto usted, pueda acceder a su información privada.
